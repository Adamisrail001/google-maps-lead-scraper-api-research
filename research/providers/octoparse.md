# Octoparse — Verification Record

**Verified:** 2026-09-23 via live fetch of https://www.octoparse.com/scraping-templates/google-maps-scraper

- **Google Maps product:** yes — no-code Google Maps scraper templates (30+ fields: names, contact info, ratings, geolocation, images, reviews), plus a dedicated "Google Maps Email Finder" template (emails, phones, social URLs).
- **Real API:** partial — Octoparse is a no-code UI platform first; it offers an "Open API Service" for task management/automation (docs referenced at /docs/en/api-reference). The API drives the UI product; it is not a standalone Maps data API.
- **Auth / self-serve:** yes — 14-day free trial with $2 free credits.
- **Pricing (published, fetched 2026-09-23):** per-template — advanced scraper $2/1,000 lines; Email Finder $0.5/1,000 lines; some templates no extra cost (plus platform subscription).
- **Email extraction:** yes — via the separate Email Finder template.
- **Intents served:** lead generation (their own positioning), business data extraction, marketed as a "Google Places API alternative". Scale/automation possible but UI-template-centric.
- **Category: ADJACENT** — real Maps + email capability, but a no-code UI product whose API is task-orchestration around the UI, not a directly consumable Google Maps data API.
